## 🌟 Sobre el proyecto

Este es mi **portfolio profesional interactivo**, diseñado para mostrar mi trabajo y experiencia de una manera dinámica y moderna. El sitio cuenta con una característica única: un **selector de perfil** que adapta el contenido según el tipo de visitante, ya sea un cliente particular (freelance) o una empresa (reclutadores).

El proyecto está optimizado para ofrecer una experiencia de usuario fluida, con soporte para múltiples idiomas, temas personalizados y animaciones elegantes.

---

## 🎭 Perfiles duales

Una de las funcionalidades más destacadas es la capacidad de alternar entre dos modos de visualización:

- **👤 Particular (Freelance):** Enfocado en servicios, flujo de trabajo creativo y testimonios de clientes. Ideal para quienes buscan contratar servicios directos de desarrollo.
- **🏢 Empresa (Corporativo):** Enfocado en la trayectoria profesional, educación y experiencia técnica. Diseñado específicamente para procesos de selección y reclutadores.

---

## 🗺️ Secciones del portfolio

El contenido se organiza dinámicamente según el perfil seleccionado:

| Sección | Descripción | Visibilidad |
| :--- | :--- | :--- |
| **Sobre mí** | Introducción personal y profesional. | Siempre visible |
| **Proyectos** | Galería de trabajos realizados con imágenes y links. | Siempre visible |
| **Servicios** | Detalle de los servicios de desarrollo ofrecidos. | Modo Particular |
| **Workflow** | El proceso paso a paso desde la idea hasta el despliegue. | Modo Particular |
| **Testimonios** | Opiniones de clientes satisfechos. | Modo Particular |
| **Educación y Experiencia** | Historial académico y trayectoria laboral. | Modo Empresa |
| **Stack Tecnológico** | Carrusel infinito con las tecnologías que domino. | Siempre visible |
| **Contacto** | Formulario directo para consultas y presupuestos. | Siempre visible |

## 🛠️ Tecnologías y herramientas

### Frontend & Core
- **React 18** + **TypeScript**: Para una estructura robusta y tipada.
- **Vite**: Como herramienta de construcción rápida.
- **SCSS**: Estilos modulares y variables dinámicas.

### Animaciones y UI
- **Framer Motion**: Animaciones fluidas y transiciones de componentes.
- **AOS (Animate On Scroll)**: Efectos de aparición al navegar por la página.
- **React Slick**: Carruseles interactivos para proyectos y tecnologías.
- **Lucide React**: Set de iconos modernos y consistentes.

### Datos y funcionalidades
- **Google Sheets API (CSV)**: Los proyectos se gestionan dinámicamente desde una hoja de cálculo.
- **Detección de Idioma**: Detección automática basada en la IP del usuario (ipapi.co).
- **Tema Dinámico**: Sistema de modo claro/oscuro persistente en LocalStorage.
